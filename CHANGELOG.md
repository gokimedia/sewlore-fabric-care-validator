# Changelog

## 1.0.0 — 2026-10-06

### Included

- A Streamlit interface for anonymous fabric-care CSV diagnostics, with an initially blank template and explicit submission.
- Input restrictions for UTF-8 CSV, byte and record limits, anonymous sample codes, controlled care-method codes and an empty notes column.
- Positive finite paired readings, matching units, signed axis contraction and optional rectangular-area contraction.
- Separate accepted-record and correction-note CSV exports with formula-like free-text neutralization.
- A labelled hypothetical demo, boundary and native app-flow checks, and local-use documentation.
- MIT-licensed source, organization-only software citation metadata and CodeMeta metadata.

The fixtures are invented software inputs; this software contains no measured fabric dataset, laboratory results or peer-reviewed study. Development and documentation were AI-assisted, with software checks and interface review.
